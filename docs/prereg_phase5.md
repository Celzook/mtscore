# 사전 등록 — Phase 5 (2026-10-29, 결과 보기 전 고정)

- **범위**: 2026-10-29에 사용자가 고른 4가지(블록 집계, 추세의 국면 보조 조건, 크레딧 추세 기준 통일, 주가지수 펀더멘털 재구성). 사용자 지시는 "1번에서 검정할 부분은 검정"이다.
- **기준선**: 브랜치 `phase4-wiki`의 현재 설정이다. 결정 1의 후보 3개는 넣지 않고, 결정 2·4는 반영된 상태다.
- **고친 기록**: 결과를 본 뒤 바꾸면 날짜와 이유를 아래 "사후 수정 기록"에 남긴다.

## 0. 공통 규칙 (`docs/prereg_2026-10-29.md` §1을 그대로 쓴다)
- **표본 분할**: 선택 구간은 2013-01-01~2019-12-31, 확인 구간은 2020-01-01~끝이다. 관측은 시작일이 속한 구간에 넣는다.
- **측정**: 63일 Spearman IC를 쓴다. 자산군별로 풀링하고, 전체 10개 자산도 풀링한다. Phase 3 풀링 방식을 그대로 쓴다.
- **유의성**: 순환 이동 플라시보 p다. 2,000회, Phase 3 시드 규칙을 따른다. 기준선과 변형에는 같은 이동 배열을 쓴다.
- **채택 조건**(모두 충족해야 함):
  1. 선택 구간 IC가 기준선보다 높다.
  2. 확인 구간 IC가 기준선 이상이다.
  3. 확인 구간 p가 기준선보다 나빠지지 않는다.
  - IC가 음수인 칸에서 조건 3은 문자 그대로 적용하고 따로 표시한다.
- **보조 지표**(판정에 쓰지 않음): 21·126·252일 IC, 국면별 이후 초과수익.
- **다중 비교**: 시험한 칸의 수를 보고서 맨 앞에 적는다.

## P5-1. 블록 집계 방법 (과매도·밸류·펀더멘털 블록, 10개 자산)
비교할 집계 방법은 아래와 같다. 하위블록 구성은 그대로 두고, 바뀌는 것은 블록 점수를 만드는 방법뿐이다.

| 코드 | 방법 | 비고 |
|---|---|---|
| base | 현행. 지표 → 하위블록 평균(confluence는 최솟값) → 하위블록 평균 | |
| R | base 블록 점수를 다시 백분위로 바꾼다 | 자기 블록 이력 대비, expanding, mid-rank. 재백분위의 최소 이력은 **252 관측(1년)**이다. 3년으로 하면 선택 구간이 너무 짧아진다. |
| D | 확산 점수 = 50 + 50 × ((블록 안 지표 중 점수 ≥80인 비율) − (점수 ≤20인 비율)) | 그날 가용한 지표 기준이다. 결과는 0~100이다. |
| M | 하위블록 안을 평균 대신 중앙값으로 집계 | 하위블록 간은 평균이다. |
| G | 하위블록 간을 산술평균 대신 기하평균으로 집계 | 0점은 0.5로 하한을 둔다. |
| P | 주성분 가중 | 블록 안 지표 점수(표준화)의 제1주성분 적재값을 가중치로 쓴다. **선택 구간 데이터로만 추정해 고정**한다. 음수 적재는 0으로 둔다. 자산군별로 추정하고, 결측일은 가용 지표로 재정규화한다. |

- **판정**: §0 규칙을 블록별·자산군별로 적용한다.
- **R의 추가 판정**(국면 기준선 50 관련): 블록 ≥50 대 <50의 63일 이후 초과수익 차이를 자산별로 계산한다. 차이가 양수인 자산×블록 수와 유의한 양수(플라시보 p<0.05) 수를 선택·확인 구간별로 base와 비교한다. 이 결과는 보고만 하고, 국면 기준 변경은 별도로 결정한다.
- **확산 표시**: D의 판정과 관계없이, 결과 출력에 "블록 안 지표 중 ≥80 개수 / ≤20 개수 / 가용 수"를 표시용으로 추가하는 것을 제안한다. 반영 여부는 사용자가 결정한다.

## P5-2. 추세를 국면 보조 조건으로 (표시 규칙, 점수 불변)
- **추세**: 현행 추세 표시 부호(12개월 초과, 결정 4 반영)를 쓴다.
- **국면 묶음**:
  - 과매도 높음 묶음: 최우선 매수, 저평가 패닉 분할 진입, 단기 반등 트레이드, 가치함정 경계
  - 과매도 낮음 묶음: 보유 분할 매수, 고점 경계, 비중 축소
- **가설**:
  - H1: 과매도 낮음 묶음 안에서 추세 ▲의 63일 이후 초과수익(자산별 무조건 평균 대비)이 추세 ▼보다 높다.
  - H2: 과매도 높음 묶음 안에서 추세 ▼의 63일 이후 초과수익이 추세 ▲보다 낮다("떨어지는 칼").
- **통계**:
  - 풀링 평균 차이(▲ − ▼)를 쓴다.
  - 겹치는 관측 때문에 유의성은 추세 부호 계열을 순환 이동한 플라시보(2,000회)로 판정한다.
  - 자산별 차이는 보조로만 쓴다.
- **채택 조건**(표시 규칙으로 쓸지): 가설마다 다음 셋을 모두 만족해야 한다.
  1. 선택 구간 차이가 가설 방향이다.
  2. 확인 구간 차이도 가설 방향이다.
  3. 확인 구간 플라시보 p ≤ 0.20.
  - 이 문턱은 표시 규칙용으로 느슨하게 미리 정한 값이다.
- **표시 규칙 초안**(채택되면 결과에 "국면 + 추세 조건" 문구를 붙인다):
  - 과매도 낮음 묶음: ▲이면 "추세 유지 중", ▼이면 "추세 약화"를 덧붙인다.
  - 과매도 높음 묶음: ▼이면 "하락 추세 진행 — 분할".

## P5-3. 크레딧 추세를 국채 대비로 통일 (표시만, 점수 불변)
- **대상**: US_HY, US_IG. KR_CORP는 이미 국고 대비다.
- **정의**: 크레딧 초과수익 근사 r_t = −D_(t−1) × Δspread_t + spread_(t−1)/252다. KR_CORP와 같은 방식이다.
  - spread는 현행 필드(평균만기 매칭 G-스프레드)를 쓴다.
  - D는 지수 수정듀레이션 `MOD_DURTN`이다(lseg 원자료, 가용일 기준). 원자료에 없으면 상수를 쓰고 그 값을 "가정"으로 적는다.
- **표시**: 12개월 누적 초과수익의 부호를 쓴다. 현금은 빼지 않고, basis는 "국채 대비"다. 출력 형식은 결정 4와 같다.
- **점검**(판정 아님):
  - iBoxx 총수익 − 매칭 국채 수익 근사와의 월별 상관
  - 부호가 바뀌는 날의 비율
  - 2022년 사례

## P5-4. 주가지수 펀더멘털 재구성 (KOSPI200, S&P500)
- **4a 묶음 가중**: 현행은 "하위블록 동일가중(earnings·macro)"이다. 변형은 "지표 동일가중(하위블록 무시, 지표마다 같은 무게)"이다. §0 규칙으로 판정한다.
- **4b 매크로 후보**: 자산당 최대 2개. 원천과 PIT를 확인할 수 있는 것만 쓰고, 없으면 N/A다(날조 금지).
  - KOSPI200
    1. 한국 수출 증가율(전년 동월 대비, 월별, 공표일 기준), 방향 +
    2. OECD 경기선행지수(한국) 6개월 변화, 방향 +
  - S&P500
    1. 미국 장단기 금리차(10년 − 3개월, FRED `T10Y3M`, 일별) 3개월 변화, 방향 +
    2. OECD 경기선행지수(미국) 6개월 변화, 방향 +
  - 각 후보를 따로 추가한 변형과, 자산별 두 후보를 함께 추가한 변형을 §0 규칙으로 판정한다(펀더멘털 블록, 자산 단위).
- **4c 이익 묶음**: 지표 구성은 그대로 둔다. Phase 3 결정 3(KOSPI 동일가중·두 종목 제외 버전)은 별도 결정 사항이라 여기서 다루지 않는다.
- **중복 규칙**: 같은 블록 기존 지표와 선택 구간 상관 > 0.9이면 제외 후보다.
