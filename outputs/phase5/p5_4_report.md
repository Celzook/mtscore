### 판정 해석 (사실과 한계)
- **4a (지표 동일가중)**
  - 풀링과 KOSPI200 모두 기각이다. 확인 구간 IC는 오르지만(KOSPI200 −0.166 → −0.025) 선택 구간 IC가 내려가고 p는 오히려 나빠진다.
  - SP500은 펀더멘털 하위블록이 `earnings` 하나뿐이라(`p5_4_fundamental_structure.csv`) 두 방식이 수치까지 같다. 풀링 칸은 이 때문에 효과가 희석돼 있다. KOSPI200 칸도 같은 결론이다.
  - KOSPI200은 현행에서 `macro` 하위블록(지표 1개, `home_ccy_trend_3m`)이 블록의 1/2을 차지한다. 지표 동일가중이면 1/5로 줄어든다.
- **4b KOSPI200**: 어느 후보도 채택 조건을 못 채운다. 기준선의 확인 구간 IC가 이미 음수(−0.166)라 "기준선 이상" 조건이 쉽게 보일 수 있으나, 조건 3(확인 p가 나빠지지 않음)은 모든 변형에서 실패한다. p가 기준선 0.435보다 낮은 변형이 없다.
- **4b SP500 CLI**
  - 세 조건을 모두 충족했다(선택 0.070 → 0.081, 확인 0.053 → 0.145, p 0.595 → 0.279).
  - 하지만 확인 구간 p = 0.279로 플라시보 기준 유의하지 않다. 선택 구간 p도 0.55 → 0.68이다.
  - 21일 IC는 선택 구간에서 낮고(0.078 → 0.071), 252일 IC는 두 구간 모두 나빠진다(선택 −0.028 → 0.063은 개선, 확인 −0.235 → −0.307은 악화). 보조 지표 혼재.
  - 6개 4b 칸 중 1개라는 점, 지표 동일가중에서는 기각되는 점(가중 방식에 민감)을 같이 봐야 한다.
  - 날짜 교집합 IC(기준선 블록이 있는 날만)에서도 통과한다(선택 0.070 → 0.110, 확인 0.053 → 0.145; `common_dates_*` 열). 즉 변형 블록이 1~2개월 먼저 시작해서 생긴 결과가 아니다.
- 중복 점검(선택 구간 상관 > 0.9): **제외 후보 없음**. 최대 상관은 SP500 CLI ~ `fwd_eps_chg_3m` 0.60, KOSPI200 수출 ~ `fwd_eps_chg_3m` 0.42. 같은 자산 두 후보끼리는 −0.30(KOSPI200), 0.03(SP500). (`p5_4_redundancy.csv`)

## 3. 가정 (검증하지 않은 것)
1. **수출 as_of = 다음 달 15일**: 산업부 속보치는 매월 1일, 통관 확정치는 그 뒤다. 두 값의 차이는 측정하지 못했다(ECOS 확정치만 있음). 15일은 보수적으로 둔 값이다.
2. **CLI as_of = 에디션 월말**: DB에 에디션 발간일이 없다. 실제는 월 중순 전후라 월말은 보수적이다.
3. **CLI 6개월 변화는 같은 에디션 안 차분**: 서로 다른 빈티지 값을 섞으면 재추정 효과가 변화로 들어가기 때문이다. 사전 등록 "6개월 변화"의 구현 선택이다.
4. T10Y3M은 최신 빈티지(일별 금리차는 수정이 없다고 가정). 미국 정부 셧다운 공표 지연은 반영하지 못한다.
5. 4b 후보는 `fundamental.macro` 하위블록에 넣는다(현행 하위블록 동일가중). SP500은 이 하위블록이 현재 없어, 후보 하나가 블록의 1/2를 차지한다.
6. 판정에는 사전 등록 구간·시평·플라시보를 그대로 쓰고, 플라시보 시드는 `placebo_seed + 5400 + 10×단위순번 + 구간순번`이다.
7. 기준선과 변형의 날짜 집합이 다르면(변형이 먼저 시작) 사전 등록 방식(Phase 4와 같음)대로 각자 날짜에서 IC를 낸다. 날짜 교집합 IC는 `common_dates_*` 열에 따로 있다.
8. 다른 레인(p5_3)이 같은 체크아웃의 `src/`를 편집하는 중에 실행했다. 재현 점검이 기준선과 동일했고 pytest 292개 통과(`p5_4_pytest_run.txt`).

### 계산하지 않은 것과 문서 불일치 (2026-10-29 검증 후 추가)
9. **전체 10개 자산 풀링 칸은 계산하지 않았다.** §0은 10개 자산 풀링도 요구한다. 이 레인이 바꾸는 자산은 KOSPI200·SP500 2개뿐이다. 그래서 10개 풀링에서는 효과가 희석돼 결론이 뒤집히기 어렵다고 본다 [추정]. 레인이 이 이유를 미리 적어 둔 것은 아니다.
10. **보조 지표 '국면별 이후 초과수익'도 계산하지 않았다.** 판정에 쓰지 않는 항목이라 판정에는 영향이 없다. 21·126·252일 IC는 `p5_4_split_ic.csv`에 있다.
11. **판정은 각 팔의 자기 날짜로 계산했다.** 스크립트 머리말은 "FIXED 비교 구간: 변형 블록은 기준선 블록이 있는 날로 자른다"고 적었는데, 실제 구현과 다르다(가정 7 참조). 예: SP500 CLI 선택 구간은 기준선 1,722일, 변형 1,762일이다. 날짜 교집합 IC는 `common_dates_*` 보조 열에 있고, SP500 CLI는 거기서도 조건 1·2를 통과한다(선택 0.070 → 0.110, 확인 0.053 → 0.145). 교집합 기준 플라시보 p는 계산하지 않았다.
12. **시드 오프셋 5400은 이 레인이 정한 상수다.** 사전 등록은 "Phase 3 시드 규칙"이라고만 했다. 검증 레인이 오프셋 1000으로 다시 돌렸더니 9칸 판정이 같았다. SP500 CLI 확인 p만 0.279 → 0.296으로 바뀌었다(검증 레인 결과, 레포 산출물 아님).
- 이 네 가지와 다른 미기록 선택은 `docs/prereg_phase5.md` "사후 수정 기록"에 함께 적었다.

## 4. 반영하면 달라지는 것 (`p5_4_impact.csv`, 2026-10-27 기준)
- **4a를 채택한다면(채택 아님)**: KOSPI200 펀더멘털 블록이 39.99 → 63.07로 바뀌어 국면이 "저평가 패닉 분할 진입" → "최우선 매수"가 된다. 확인 구간의 ≥50 판정이 26%의 날에서 뒤집힌다. 기각이라 반영하지 않는다.
- **SP500 CLI(조건 충족 후보)를 반영한다면**
  - SP500 블록이 78.9 → 74.3으로 내려가고 국면은 "단기 반등 트레이드"로 그대로다.
  - 확인 구간에서 블록 ≥50 판정이 18.6%의 날에서 달라지고, 기준선 블록과의 상관은 0.84다.
  - 구현에는 코어 변경이 필요 없다. `universe.yaml`의 SP500 `overrides.add`에 `fundamental.macro`로 `us_cli_chg6m`을 추가하면 된다. 다만 입력 파이프라인(OECD 개정 DB 수집과 에디션 내 차분)을 새로 붙여야 한다. 이 비용과, 에디션이 비는 달이 있고(2016-07·08, 2020-03, 2024-08, 2025-08, 2026-08) 외부 DB가 바뀔 위험이 따른다.
- 이 레인은 설정·코어·테스트를 바꾸지 않았다. 반영 여부는 사용자가 정한다. 근거가 약하다(1/6칸, p = 0.279, 가중 방식 민감). 보고만 한다.
- 기준선 KOSPI200 펀더멘털 블록은 확인 구간 IC가 음수(−0.166; 126일 −0.233, 252일 −0.397)다. 4a·4b 어느 변형도 이를 고치지 못한다. 이익 묶음(4c) 구성 문제는 사전 등록상 이 레인 범위 밖이다.
