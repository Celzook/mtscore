Phase 4 결과와 정하실 것

10-29에 정하신 검토(변동성 가점, 추세 표시, 장기 반전, 캐리, CAPE, 기술적분석 시험대)를 모두 마쳤습니다. 단계마다 별도 검증 레인을 통과했고, 결과는 phase4-wiki 브랜치에 합쳐 GitHub에 올렸습니다(테스트 266개 통과). 점수 설정은 아직 아무것도 바꾸지 않았습니다. 아래 결정을 주시면 그대로 반영하고 다시 검증합니다.

  • 분할 진입 표시와 추세 표시는 이미 결과 출력에 들어갔습니다(점수·국면 영향 없음, 결과 스키마 1.1).

2. 정하실 것

결정 1. 채택 조건을 충족한 후보 3개 (원자재 장기 반전, 환율 금리차 수준, S&P500 CAPE)

  • 근거: 세 후보 모두 선택·확인 두 구간에서 IC가 올랐고, 기존 지표와 중복도 없습니다(최대 상관 0.70). 다만 유의하지 않고, 보조 지표에 주의할 점이 있습니다.
    • 원자재 장기 반전: 확인 구간 1년 IC는 0.16→0.10으로 낮아집니다.
    • 환율 금리차: 확인 구간 1년 IC가 기존·변형 모두 음수입니다(−0.22, −0.23).
    • S&P500 CAPE: 1년 IC도 높아집니다(확인 0.18→0.40). 다만 1년 수익은 서로 겹쳐서 독립 표본이 7개 안팎입니다. 또 CAPE가 2009년 이후 대체로 오르기만 해서 지금 점수가 0~2점에 몰려 있습니다. 반영하면 S&P500 밸류 블록이 지금보다 내려갈 가능성이 큽니다[추정]. 결정 3이 먼저 정해져야 합니다.
    • 원자재 장기 반전: 개선이 새 지표 자체보다 블록 구성에서 왔을 수 있습니다(새 지표 단독 IC 0.077 < 기존 지표 0.143).
  • 선택지: (가) 사전 등록 규칙대로 셋 다 반영, "효과 미확인" 표기 · (나) 반영하지 않음 · (다) 일부만
  • 권고: (가). 결과를 보기 전에 정한 규칙이 이 셋을 "채택"으로 판정했습니다. 다만 사전 등록은 "통과해야 반영할 수 있다"는 필요조건입니다. 반영하지 않는 (나)도 기준을 어기는 것이 아니고, 최종 판단은 사용자 몫입니다.
  • 반영하면 해야 할 일: 설정만 바꾸는 일이 아닙니다.
    • 원자재 장기 반전: 2005년부터의 장기 가격 빌드를 주 데이터 빌드에 넣어야 합니다(원자료는 저장소에 없고 Refinitiv로 다시 받아야 재현됩니다).
    • S&P500 CAPE: Shiller 이익과 1999~2006 CPI 빌드를 주 데이터 빌드에 넣어야 합니다.
    • 환율 금리차 수준: 기존 필드로 바로 됩니다.
    • 반영 뒤 현재(10-27) 점수·국면이 어떻게 바뀌는지 계산해 보여 드리고, 기본 점수 재현과 블록 IC를 다시 확인합니다. 바뀌는 양은 아직 계산하지 않았습니다.

결정 2. 지금 점수에 들어 있는 변동성 가점(무조건형)과 볼린저×RSI 동시 판정

  • 근거
    • Phase 3: 10-28 역발상 개편(동시 판정·변동성 가점)은 개편 전보다 나아지지 않았습니다. 주가지수는 개편 전이 조금 더 좋았습니다(유의하지 않음).
    • Phase 4: 조건부판은 전체에서 기각됐습니다. 변동성 지표를 아예 빼는 안도 전체 선택 구간에서 나빠졌습니다(0.049→0.040).
    • 볼린저 동시 판정은 10-29에 "유지"로 정하셨습니다.
  • 참고: 환율(USDKRW 하나)만 놓고 보면 조건부판이 세 조건을 충족했지만, 변동성 지표를 빼는 쪽이 세 조건 모두 더 좋았습니다(선택 0.083, 확인 0.050, p 0.637). 전체로는 빼는 안이 선택 구간에서 나빠졌고, 확인 구간은 조금 나아졌습니다(−0.051→−0.045). 자산 하나의 결과라 환율만 따로 바꾸는 것은 권하지 않습니다.
  • 선택지: (가) 지금처럼 유지, "효과 미확인" 표기 · (나) 변동성 가점만 제거 — 이 경우 분할 진입 표시가 읽을 변동성 지표가 없어져, 표시가 비게 됩니다(코드 수정 필요) · (다) 개편 전체 되돌리기(Phase 3 결정 4)
  • 권고: (가). 바꿀 근거도, 유지할 근거도 없습니다. 바꾸려면 사전 등록 검증이 필요한데, 이미 두 번 시험해서 차이가 나오지 않았습니다. 변동성은 분할 진입 표시로 별도로 보여 줍니다.

결정 3. 미국 CPI 2025-10 결측 (S&P500 CAPE에 영향)

  • 문제: 셧다운으로 이 달 CPI가 공표되지 않았습니다. 사전 등록 정의("120개월이 모두 있어야 계산")대로면 2026-04-24 이후 약 10년간 CAPE가 없습니다.
  • 선택지: (가) 빠진 달을 건너뛰고 최근 120개 가용 월로 계산 · (나) 사전 등록 정의 그대로(CAPE 사실상 사용 불가) · (다) 앞뒤 달로 보간
  • 권고: (가). 판정이 같고 공표되지 않은 값을 지어내지 않습니다. (다)는 없는 값을 만드는 것이라 권하지 않습니다. 다만 결과를 본 뒤의 사후 수정이고, (가)의 숫자(확인 IC 0.181, p 0.373)가 사전 등록 정의(0.171, p 0.433)보다 조금 유리하다는 점을 밝혀 둡니다. 창이 달력 121개월에 걸치는 것도 정의와 다릅니다. 날짜를 남겨 사전 등록을 고칩니다.

결정 4. 국내 회사채 추세 표시

  • 문제: KR_CORP 수익 지수는 같은 듀레이션 국고 대비 초과수익의 근사(가정)인데, 추세 표시에서 현금 수익을 한 번 더 뺍니다. 그래서 ▲가 나오는 날이 7.6%뿐입니다.
  • 선택지: (가) KR_CORP는 현금을 빼지 않음(이미 초과수익) · (나) 지금 그대로
  • 권고: (가). 같은 것을 두 번 빼는 셈입니다. 다만 지금 코드는 모든 자산에서 현금을 일괄로 빼서, 자산별 예외를 두려면 코드(api.py·config.py)를 고쳐야 합니다. 사전 등록 B3 정의도 날짜를 남겨 고칩니다. 고치면 KR_CORP의 ▲·▼는 "국고 대비", 다른 자산은 "현금 대비"로 뜻이 달라진다는 점도 표시합니다. 점수에는 영향이 없습니다.

결정 5. 국면 판정 기준 50점 (Phase 3 결정 2)

  • 문제: 블록 점수의 중앙값이 자산마다 크게 다릅니다. 밸류 블록을 예로 들면 S&P500 12, WTI 65입니다. 그래서 같은 "50 이상"이 자산마다 다른 뜻이 됩니다. S&P500은 밸류 50 이상인 날이 2%뿐입니다.
  • 선택지: (가) 지금은 50 유지, 대시보드 이식 때 다시 검토 · (나) 자산별 기준선(예: 자기 블록 중앙값)으로 바꾸고 표본 분할로 검증
  • 권고: (가). 바꾸는 것은 튜닝이라 사전 등록 검증이 필요합니다. 대시보드 유니버스(50개 이상)가 정해진 뒤 한 번에 하는 편이 낫습니다.

3. 함께 남아 있는 것

  • Phase 3에서 미룬 결정: 통화 이중반영 변형(결정 1, 현행 both 유지 권고), KOSPI200 이익 지표 가중(결정 3, 표본 분할 확인 후 변경 권고), USDKRW 경상수지 정규화(결정 5).
  • main 병합: mtscore의 Phase 1 이후 작업은 모두 main 밖에 있습니다. phase3-backtest까지 포함한 phase4-wiki를 main에 합칠지는 위 결정을 반영한 뒤 여쭙겠습니다.
  • 보류 중: 임계값 이벤트 방식(트리거 포인트)은 말씀하신 대로 보류 상태입니다. 대시보드 유니버스(50개 이상)는 목록을 주시면 진행합니다.
  • 정리할 것: 작업 폴더 mtscore-c, mtscore-d, mtscore-d2는 병합이 끝났으니 지워도 됩니다.
